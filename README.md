# Голосовой перевод в реальном времени

Локальное Linux-приложение для двунаправленного голосового перевода в реальном времени:

- `RU => EN`: вы говорите по-русски, наружу уходит английская синтезированная речь
- `EN => RU`: входящая английская речь переводится и озвучивается вам в наушники на русском

Текущая версия рассчитана на живой разговор, Telegram, Google Meet, Zoom, YouTube и другие приложения, где можно выбрать виртуальные аудиоустройства PulseAudio / PipeWire.

## Что умеет приложение

- автоматически поднимает backend `EN => RU`
- показывает отдельное окно статусов backend-ов
- создаёт и использует виртуальные аудиоустройства:
  - `TranslatorMicrophone`
  - `TranslatorListen`
  - `TranslatorMic`
- даёт управлять двумя ветками из одного окна:
  - `Говорить RU=>EN`
  - `Слушать EN=>RU`
- позволяет ставить каждую ветку на паузу
- позволяет заглушать или приглушать оригинальную английскую речь
- пишет рабочие логи в `logs/app.log`

## Актуальная архитектура

### Ветка `EN => RU`

- `STT`: `whisper.cpp` server
- `VAD / сегментация`: `Silero VAD`
- `Перевод`: `Helsinki-NLP/opus-mt-en-ru`
- `TTS`: `Piper`, голос `ru_RU-dmitri-medium`

### Ветка `RU => EN`

- `STT`: `faster-whisper`
- `Перевод`: `Helsinki-NLP/opus-mt-ru-en`
- `TTS`: `Piper`, голос `en_US-ryan-medium`

## Аудиоустройства

Приложение использует два понятных виртуальных устройства:

### `TranslatorMicrophone`

Это виртуальный микрофон для исходящей речи.

Его нужно выбирать как микрофон в:

- Telegram
- Google Meet
- Zoom
- Discord
- любом другом приложении, где собеседник должен слышать ваш перевод

Поведение:

- `Продолжить` в блоке `Говорить RU=>EN`:
  наружу идёт английская синтезированная речь
- `Пауза`:
  наружу идёт ваш оригинальный русский голос

### `TranslatorListen`

Это виртуальный sink для входящей речи, которую вы хотите переводить себе.

Пример:

- если хотите переводить YouTube, во вкладке `Воспроизведение` в `pavucontrol` для `Google Chrome` выберите `TranslatorListen`

Поведение:

- приложение слушает `TranslatorListen.monitor`
- оригинальная английская речь и русский перевод идут вам в наушники
- кнопки `Заглушить / Приглушить / Слушать 100%` управляют слышимостью оригинала

## Как это использовать

### Сценарий 1. Вы говорите собеседнику, собеседник слышит английский

1. Запустите приложение.
2. Дождитесь, пока окно статусов покажет, что backend-ы готовы.
3. В Telegram / Meet / Zoom выберите микрофон:
   `TranslatorMicrophone`
4. В приложении оставьте `Говорить RU=>EN` в режиме `Продолжить`.

Результат:

- вы говорите по-русски
- собеседник слышит английский синтез

Если нажать `Пауза`:

- собеседник будет слышать ваш оригинальный русский голос

### Сценарий 2. Вы слушаете английскую речь и слышите русский перевод

1. Откройте `pavucontrol`.
2. Во вкладке `Воспроизведение` выберите для нужного приложения sink:
   `TranslatorListen`
3. В приложении оставьте `Слушать EN=>RU` в режиме `Продолжить`.

Результат:

- английская речь идёт в `TranslatorListen`
- приложение переводит её на русский
- русский перевод звучит у вас в наушниках

### Сценарий 3. YouTube

1. Запустите YouTube в браузере.
2. Во вкладке `Воспроизведение` в `pavucontrol` для `Google Chrome` выберите:
   `TranslatorListen`
3. Запустите пайплайн.

## Что происходит при запуске

После старта `main.py`:

1. создаётся `QApplication`
2. загружается `app_config.json`
3. запускается `BackendManager`
4. открывается отдельное окно статусов backend-ов
5. проверяется и при необходимости поднимается `whisper.cpp`
6. `RU => EN faster-whisper` подготавливается как встроенный runtime
7. открывается основное окно приложения

## Запуск

Из корня проекта:

```bash
.venv/bin/python main.py
```

### Отдельно `whisper.cpp`

Если нужно запустить сервер вручную:

```bash

```
